# Proposal: polish-map-ui

## Summary

优化地图页面布局和矢量图层样式，提升用户体验。

## Problem

当前地图页面存在以下问题:

1. **布局问题**: 地图区域高度不足，仅占约三分之一视口
2. **可读性问题**: 矢量图形颜色与底图接近，难以辨识
3. **功能缺失**: 缺少缩放按钮，用户难以快速定位数据范围

## Solution

### 1. 调整页面布局

- 地图区域占满视口高度 `calc(100vh - 60px)`
- 左侧图层面板固定宽度 280px，可折叠
- 移除不必要的 padding

### 2. 优化矢量图层样式

- 填充色: `rgba(255, 140, 0, 0.4)` (橙色半透明)
- 边框色: `#ff6b00` (深橙色)
- 线宽: 2px

### 3. 添加要素悬停高亮

- 鼠标移入时边框加粗、填充变亮

### 4. 添加缩放到数据按钮

- 浮动按钮，点击后缩放到所有已加载矢量数据的范围

## Scope

- `frontend/src/views/map/index.vue` - 页面布局
- `frontend/src/views/map/MapContainer.vue` - 图层样式、交互

## Success Criteria

- [ ] 地图区域占满视口高度
- [ ] 矢量图形清晰可见，颜色与底图形成对比
- [ ] 鼠标悬停时要素有高亮效果
- [ ] 缩放到数据按钮功能正常
- [ ] 左侧面板可折叠/展开
