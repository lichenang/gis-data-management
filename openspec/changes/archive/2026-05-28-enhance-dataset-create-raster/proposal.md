# Proposal: enhance-dataset-create-raster

## 问题描述

数据集创建对话框已有"类型"下拉框（可选矢量/影像），但选择"影像"类型后没有对应的上传组件。后端已实现完整的影像上传接口（`POST /api/v1/images/upload`），前端影像管理页也已正常使用，唯独数据集创建流程中缺少影像上传集成。

用户只能先通过"影像管理"页面上传 GeoTIFF，再回到数据集页面管理，流程割裂。

```
数据集创建对话框
  ┌───────────────────────────┐
  │ 类型: [影像 ▼]           │
  │                           │
  │ 📁 上传空间数据（可选）    │
  │                           │
  │  (空 — ❌ 无法上传影像)   │
  │                           │
  │ [取消] [仅创建] [导入]    │
  └───────────────────────────┘
```

## 目标

在数据集创建对话框中，当用户选择"影像"类型时，显示 GeoTIFF 上传组件，调用现有的后端影像上传接口，上传成功后自动刷新数据集列表。

```
  ┌───────────────────────────┐
  │ 类型: [影像 ▼]           │
  │                           │
  │ 📁 拖拽 GeoTIFF 到此处    │
  │   支持 .tif/.tiff        │
  │                           │
  │ [取消] [仅创建] [上传影像]│
  └───────────────────────────┘
```

## 影响范围

- 仅修改 `frontend/src/views/datasets/index.vue`
- 新增 `import { uploadImage } from '@/api/image'`
- 不修改后端、不修改 API 层、不修改其他组件
