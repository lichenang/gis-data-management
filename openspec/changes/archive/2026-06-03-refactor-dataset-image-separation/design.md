## Context

当前两个管理页面都混入了类型选择逻辑，但实际上它们应该各自专注于一种数据类型：

```
当前状态:
┌─────────────────────────────────────────────────────────────┐
│  datasets/index.vue                                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 新建: [名称] [类型▼] ← 应隐藏                          │   │
│  │       └─矢量/影像                                      │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│  images/index.vue                                           │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 新建: [名称] [类型▼] ← 应隐藏                          │   │
│  │       └─矢量/影像                                      │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## Goals / Non-Goals

**Goals:**
- 大幅简化新建表单，隐藏类型选择
- datasets 固定 vector，images 固定 raster
- 编辑时类型不可修改

**Non-goals:**
- 不修改后端接口
- 不添加新功能

## Implementation

```vue
<!-- datasets/index.vue -->
<el-form-item label="类型" prop="type" v-if="isEdit">
  <!-- 编辑时显示，但禁用 -->
  <el-select v-model="form.type" disabled>
</el-form-item>
<!-- 新建时整个表单项隐藏 -->

<!-- handleCreate 中确保默认值 -->
const handleCreate = () => {
  form.type = 'vector'  // 明确设置
}
```

## Risks / Trade-offs

| 风险 | 描述 | 缓解措施 |
|------|------|----------|
| 后端依赖 type 字段 | CREATE 时不传 type 可能报错 | 验证后端接口容错性 |
